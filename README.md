# Employee Management System

A modern Employee Management System built with **React.js and Vite**. The application provides separate dashboards for administrators and employees, helping manage tasks through a clean and responsive interface.

## 🚀 Features

- Admin Dashboard
- Employee Dashboard
- Task Management
- Create and assign tasks
- View task status
- Responsive user interface
- Role-based dashboard experience

## 🛠️ Tech Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- HTML5
- CSS3

## ⚙️ Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### Installation

```bash
git clone https://github.com/Saiyaaj/employee-management-system.git
cd employee-management-system
npm install
npm run dev
